# Welico

Source for [welico.com](https://www.welico.com), built with [Astro](https://astro.build).

```
npm install
npm run dev      # local dev server
npm run build    # outputs to dist/
```

Docs for this project live in the Obsidian vault under
`10_Projects/Products/Welico/Docs/` (PRD, ADR, Wireframes).
